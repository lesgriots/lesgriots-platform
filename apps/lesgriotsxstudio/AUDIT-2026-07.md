# AUDIT — lesgriotsxstudio.com · Juillet 2026

Audit complet (technique, design/UX, contenu). Verdict global : **base visuelle solide et alignée marque** (esthétique terminal, Geist Mono, ASCII griot — cohérent avec « souverain et calme »), mais **le poids du site est intenable** (892 Mo d'assets).

> **Parti pris assumé (Moos, 07/2026)** : c'est un **portfolio premium** — pas de tarifs publics, pas de formulaire de demande entrante. Le contact = `studio@lesgriots.com` dans About, point. Les recommandations « funnel » initiales sont retirées.

---

## P0 — CRITIQUE

### 1. Code mort du formulaire INQUIRY à trancher
- `inquiry.jsx` (133 lignes) n'est jamais chargé ni monté — cohérent avec le positionnement portfolio, mais alors **le supprimer** (ou l'archiver) avec la clé i18n `menu.inquiry`, pour que le repo reflète la décision.

### 2. 892 Mo d'images/vidéos servis depuis `img/`
- `oumar-yeezy.mp4` = 191 Mo · `img/nike/` = 228 Mo · `EDIT_END OF SURVIVAL...MOV` = 70 Mo (un .MOV brut !) · 23 fichiers > 5 Mo · screenshots PNG 8–17 Mo.
- Mobile 4G = site inutilisable ; bande passante VPS explosée.
- **Fix** : réencoder toutes les vidéos en H.264 1080p ~5 Mbps (ffmpeg), viser < 15 Mo/vidéo ; convertir les PNG lourds en WebP/JPEG ; supprimer les doublons (.web.mp4 vs mp4). Objectif : dossier < 100 Mo.

### 3. Aucune mention légale
- Obligation LCEN pour un site commercial français. Aucune page legal/privacy.
- **Fix** : page `/legal` avec SASU LES GRIOTS, SIREN 902 628 684, siège Le Havre, hébergeur OVH.

### 4. Vocabulaire pilier 2 obsolète
- `ecosysteme.jsx:127` affiche encore « PLATEFORME ÉDITORIALE » → doit être « PRODUCTION ORIGINALE & IPs » (bible juin 2026).

### 5. Fichiers de dev shippés en prod
- `tweaks-panel.jsx` (568 lignes, panneau debug CRT/grain) chargé et monté pour tous les visiteurs (`index.html:45`, `app.jsx:274`).
- `index v1.html`, `test-scroll-logo.html`, dossier vide `lesgriotsxstudio/` imbriqué, `screensaver.jsx` + `stickers.jsx` non montés.
- **Fix** : condition `hostname === "localhost"` pour TweaksPanel ; supprimer/déplacer le reste vers `_archive/`.

## P1 — IMPORTANT (à faire dans la foulée)

6. **SEO quasi nul** : `<body>` = `<div id="root">` vide, title générique, pas de meta description, pas d'OpenGraph (partage LinkedIn/Slack = carte vide), pas de robots.txt/sitemap. Fix : title descriptif + meta + og:image + un bloc `<noscript>` avec contenu texte de base.
7. **Boot screen 3 s minimum imposées** (`boot.jsx` MIN_DURATION 3000) sur première visite, après le chargement de React+Babel CDN. Réduire à ~1,5 s et afficher une progression.
8. ~~Tarifs publics~~ — retiré : positionnement premium, sur devis uniquement.
9. **Footer sans maillage écosystème** : aucun lien vers lagriotheque.com / lesgriots.com hors page Eco. Ajouter les 2 liens au footer.
10. **Accessibilité** : aucun `prefers-reduced-motion` (83 keyframes, grain + CRT sweep en boucle infinie), alt vides sur la galerie, pas de `:focus-visible`. 3 fixes CSS rapides.
11. **Dépendance unpkg sans fallback** : unpkg down = site mort. À terme : pré-compiler les .jsx (esbuild) et servir React en local — supprime aussi l'overhead Babel runtime (~800 Ko + compilation client).
12. **Breakpoints anarchiques** : 7 valeurs (600/700/760/820/900/1100/1200) avec des `@media 760px` redéfinis 60 lignes plus loin. Consolider sur 760 / 1200.

## P2 — MINEUR

13. Clés i18n vides (`home.locs`, `foot.locs`), `--font-mono` dupliqué, 4 familles Google Fonts chargées pour 1 utilisée, curseur SVG inline dupliqué, logique `servicesOf()`/`cascadeDelays()` copiée entre fichiers, cache-buster `?v=` statique à bumper manuellement, pas de flèches clavier dans le viewer, Médine et CCN Le Havre absents du portfolio.

## Ce qui est déjà bien
SRI sur les CDN, lazy loading images, routing History API propre et URLs partageables, i18n FR/EN complet et sans faute, vocabulaire interdit absent, 6/8 clients bible présents, easing/durées d'animation cohérents.
